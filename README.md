# Biblioteca ILK

1. Coloque a logomarca em `public/logo.png`.
2. `npm install` e `npm run dev` para testar localmente.
3. Netlify: envie o projeto ao GitHub (ou arraste a pasta) com build `npm run build` e publicação `dist` (já em netlify.toml).
4. No Supabase: desative "Allow new users to sign up" em Authentication > Providers > Email e crie manualmente o usuário da administradora.
5. Em Authentication > URL Configuration, adicione o endereço do site Netlify em Site URL.
